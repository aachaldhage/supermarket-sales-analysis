\# Supermarket Sales Analysis \& Business Intelligence Dashboard



This project focuses on analyzing supermarket sales data using Python, Exploratory Data Analysis (EDA), data visualization, and Power BI to generate meaningful business insights.

\## Dataset



The project uses supermarket sales transaction data containing information about customer type, gender, product category, unit price, quantity, total sales, and payment method.



\## Tools Used



\- Python

\- Pandas

\- Matplotlib

\- Seaborn

\- Power BI

\- Git

\- GitHub



\## Project Workflow



Dataset → Data Cleaning → Exploratory Data Analysis → Data Visualization → Power BI Dashboard → Business Insights → Recommendations
